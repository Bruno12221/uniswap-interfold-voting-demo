# Contributing

Use synthetic data and keep the poll separate from official governance. Read README.md and the architecture, feasibility, privacy and reproduction guides before changing behavior.

Use a separate branch for implementation. Run meaningful checks, inspect the complete staged file list and preserve upstream licenses/notices. Keep credentials, private ballots, witnesses, encryption randomness, logs, databases, proofs and dependencies out of Git.

Do not broaden the sole approved local replay policy, silently round weights, add a new encoding or describe fixtures as real services. Preserve the full admitted transcript and verified-result failure controls. No deployment, spending, hosting, outreach or governance execution is authorized by local development. Do not repeat completed aggregate computation for routine review.
